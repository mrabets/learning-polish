# Część 2A — Prezentacja: как сдать правильно (конспект купленной книги + план)

> Источник: **Ewa Pawleta, «Prezentacja — twój klucz do certyfikatu», telc B1-B2** (куплена учеником 2026-08-19, PDF в `mowienie/prezentacja_twoj_klucz_pawleta.pdf`). Метод книги: 3 темы × 3 версии ответа (A → B → C) с разбором, почему A = слабый B1, B = хороший B1, C = B2.
> Старт этапа: **суббота 2026-08-22**.

## 1. Что требует telc от презентации (по книге, стр. 2)

К презентации МОЖНО подготовиться заранее в 20 минут подготовки: **выписать план и аргументы** и пользоваться ими на экзамене (⛔ но НЕ читать целиком — потолок A2, официальный документ стр. 35).

Презентация обязана:
1. **Иметь композицию:** `wstęp → rozwinięcie → zakończenie`
2. **Раскрывать тему МНОГОАСПЕКТНО** — не только свой опыт/свою перспективу, а прежде всего:
   - `plusy i minusy` / `korzyści i zagrożenia` (выгоды и угрозы)
   - `zmiany na przełomie wieków` / `życie różnych pokoleń` (как было раньше ↔ как сейчас, поколения)
3. Длительность: книга говорит **«na prezentację około 3 minuty»** на человека (официальный тест: Część 2 ≈ 3 мин/чел, из них сама речь 2A ≈ 2 мин + вопросы 2B).

## 2. Лестница A → B → C (главный урок книги)

| Версия | Что это | Почему такой уровень |
|---|---|---|
| **A** (≈100 слов) | Только личная перспектива, одна сторона темы | B1, но «za krótki», «częściowo na temat» — тема раскрыта частично |
| **B** (≈200 слов) | Личная перспектива + плюсы И минусы + подытог | **Хороший B1** («dłuższa, rozbudowana, kompozycja lepsza») — но «wciąż za mało na B2»: нет широкого взгляда |
| **C** (≈250–300 слов) | Обе стороны темы + обобщения об обществе + абстрактная лексика + личное только как отправная точка | **B2** («akademicka, w pełni realizuje temat») |

**Разница B ↔ C (дословно из анализов):** B = «przede wszystkim perspektywa osobista, brakuje spojrzenia wieloaspektowego»; C = «perspektywa osobista jest punktem wyjścia do uogólnionych rozważań», «słownictwo abstrakcyjne, a nie tylko konkretne», «uogólnia, nazywa przyczyny zjawisk».

## 3. 🎯 ФОРМУЛА ДЛЯ УЧЕНИКА (цель: уверенный B1 = уровень B, тянемся к C)

Ученик уже умеет уровень A/B — это его каркасы 1B. Чтобы дотянуть ответ 1B до презентации 2A, нужно ДОБАВИТЬ:

```
1. WSTĘP (2–3 предложения) — рамка темы, НЕ с себя:
   «Wybór między X a Y nie jest dziś prosty, ponieważ oba mają swoje zalety i wady.»
   «Coraz częściej ludzie zastanawiają się nad…»
2. ROZWINIĘCIE — 3 блока:
   a) Сторона 1 / plusy  («Przede wszystkim… Poza tym…»)
   b) Сторона 2 / minusy («Z drugiej strony…»)
   c) ⭐ ЛИЧНЫЙ ПРИМЕР как иллюстрация («Znam to z własnego doświadczenia: …»)
      + ⭐ БЛОК «kiedyś ↔ dziś» («Moi rodzice / dziadkowie nie mieli tylu możliwości…
      Dziś wszystko się zmieniło…») — самый дешёвый способ дать «wieloaspektowość»
3. ZAKOŃCZENIE (2 предложения):
   «Podsumowując, zarówno X, jak i Y mają swoje plusy i minusy.»
   «Wybór zależy od indywidualnych potrzeb i tego, co dla danej osoby jest najważniejsze.»
```

**Два готовых «аспектных» хода, которые превращают B в C:**
- **Поколения:** `Moi rodzice nie mieli tylu możliwości, co my dzisiaj` → `Wszystko się zmieniło` (тексты подróże A/B/C построены ровно на этом)
- **Общество вместо себя:** `Wiele osób…` · `Coraz częściej ludzie…` · `Współczesny świat daje nam coraz więcej możliwości, ale jednocześnie zmusza do podejmowania trudnych decyzji`

## 4. Золотые фразы из текстов C (заучить 8 штук)

| Фраза | Где ставить |
|---|---|
| `Wybór między X a Y nie jest dziś prosty, ponieważ oba mają swoje zalety i wady.` | wstęp |
| `Współczesny świat daje nam coraz więcej możliwości, ale jednocześnie zmusza do podejmowania trudnych decyzji.` | wstęp |
| `Przede wszystkim…` | первый аргумент |
| `Warto też podkreślić, że…` | доп. аргумент |
| `Z drugiej strony, … wiąże się z …` | минусы |
| `Znam to z własnego doświadczenia.` | мостик к личному примеру |
| `Podsumowując, zarówno X, jak i Y oferują różne możliwości i wyzwania.` | zakończenie |
| `Wybór zależy od indywidualnych potrzeb, etapu życia oraz tego, co dla danej osoby jest najważniejsze.` | финальная фраза |

## 6. План этапа 2A (старт суббота 2026-08-22)

1. Разминка: 8 золотых фраз (русский смысл → польская фраза).
2. Тема 1 — «Życie na wsi i w mieście»: ученик читает вслух текст C из книги → строит СВОЮ версию по формуле (план из 4–6 опорных слов, НЕ текст) → рассказывает по плану → follow-up 2B (1–2 вопроса).
3. Так же темы 2 и 3 из книги, потом остальные из топ-10 (rodzina, zdrowie, praca zdalna, telefon/technologia, języki obce, sława, hobby).
4. ⏱️ Ближе к концу — прогоны с таймером на 2–3 минуты и голосовые записи (Płynność/Wymowa = 20 б.).
5. ⛔ Каждый раз: план = опорные слова, декламация запрещена (потолок A2).

## 7. Правила ведения дрилла 2A (для агента)

- Роль экзаменатора, на «ty». Давать тему + 20 «минут» подготовки символически: ученик пишет 4–6 опорных слов (можно по-русски) и говорит по ним.
- Проверка по 4 осям книги: **na temat? · wieloaspektowo? · kompozycja (wstęp/rozwinięcie/zakończenie)? · długość (~15–20 предложений)?**
- Ошибки — по жёсткому правилу: только формы глагола/согласование + повторы, макс. 2–3 пункта.
- После презентации ОБЯЗАТЕЛЬНО 1–2 вопроса 2B по её содержанию.
- Цель: уровень B (уверенный B1). Ходы уровня C (`поколения`, `общество`) предлагать как опции, не требовать.
