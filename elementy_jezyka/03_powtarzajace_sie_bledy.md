## 3) Правила-триггеры

1. **`który`:** глагол ПОСЛЕ него из списка `oczekiwać · potrzebować · brakować · szukać` или с `nie` перед ним → `którego / której / których`. Иначе — по-русски.
2. **Связка:** после пропуска существительное → `pomimo` / `z powodu`; целое предложение с глаголом → `mimo że` / `ponieważ`; перед `, że` — только `dlatego`. «Всё равно, хотя…» → `pomimo` / `mimo że` / `mimo to`.
3. **`o` + слово:** окончание вин. п. (`kurs`, `zmianę`, `zwrot`) → просить / спрашивать / `chodzi`; предл. п. (`kursie`, `zmianie`) → говорить / сообщать / узнать. **Если пропуск — глагол, сначала посмотри окончание после `o`.**
4. **`z`:** «с, согласно» (`zgodnie z`, `w związku z`, `sąsiadujący z`) → твор. `-ą/-em/-ami`. «Из, от, чем недоволен» (`niezadowolony z`, `zrezygnować z`, `korzystać z`) → род. `-y/-u/-ów`.
5. **После `być`:** есть подлежащее → «какой?» `-y/-a/-e/-i`. Подлежащего нет (`w pokoju było…`) или глагол действия (`odpowiadał…`) → `-o/-ie`.
6. **Подлежащее:** глагол может стоять впереди (`przeszkadza mi…`, `nie podoba mi się…`). Спроси «кто/что?» → им. п. `nie` здесь родительный НЕ делает.
7. **Местоимение после `nie`:** их много → `ich`; она одна → `jej`; он/оно одно → `go`.
