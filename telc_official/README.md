## ⚠️ Важно

- Для польского B1-B2 существует **только ОДНА версия пробника** (Übungstest 1). Второй официальной версии нет — в отличие от немецких экзаменов telc, где есть Übungstest 2.
- Значит, официальных telc-материалов больше взять неоткуда. Всё остальное на рынке — сборники «по образцу» от сторонних издательств.
- 15 тестов в `testy_certyfikatowe_B1/` — это **państwowy egzamin certyfikatowy**, ДРУГОЙ экзамен и другой формат. Для telc они не подходят напрямую (но годятся как общая тренировка чтения/аудирования на уровне B1).
